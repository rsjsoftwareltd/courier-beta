# Courier beta

Beta builds of [Courier](https://github.com/rsjsoftwareltd/courier): newer than the public release, for trying new features
before they reach everyone. Each beta is tested by RSJ Software but may still have rough edges.

**To be offered betas:** in Courier, Settings -> Updates -> Update channel -> **Beta**. You are also offered every public
release as it comes out. Tick **Allow automatic updates** there too if you want them installed without asking. Switching back to
**Stable** never installs an older version.

**To install one by hand:** download `CourierSetup.exe` from the newest release here and run it over your existing install.
Each release lists the installer's SHA-256 checksum.

This repository holds releases only. For everything else, use the main repository:
- [Documentation (wiki)](https://github.com/rsjsoftwareltd/courier/wiki)
- [Bug reports and feedback (Issues)](https://github.com/rsjsoftwareltd/courier/issues)
